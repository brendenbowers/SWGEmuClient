# SWG Emulator Unreal Client

A very basic client in unreal to connect to SWGEmu servers. 
Requires the tre files from a Retail client to convert the assets to be used in unreal.
It exists to see how porting an old game client to unreal can be done. 

### What Works
- Login Credentials, Galaxy select, and Character Select
- Loading the planet, buildings, NPCs, Creatures, Objects and Players in a small area
- Basic movement with animations
- Equipped armor and some weapons
